# Retired RDT LLM material

This archive contains historical evaluation, rollout, and rollback material for the retired RDT LLM service. It is preserved for traceability only. Do not run its scripts, use its old provider/model/minion targets, or treat its evaluation results as current.

The active Salt targeting and RDT-specific evaluation entry points have been removed from this repository candidate. The generic Caddy bearer-auth capability is retained; host-specific Caddy settings are not being changed here. No live Salt state was applied by this change; live service cleanup, electrical shutdown verification, and asset disposition remain separate workstreams.
